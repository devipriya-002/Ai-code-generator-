# 🤖 AI Code Generator

An AI-powered web application that generates code from natural language prompts. Simply describe what you want to build, and the application generates code instantly using an AI language model.

## ✨ Features

- 🧠 Generate code from plain English prompts
- 💻 Supports multiple programming languages
- ⚡ Fast AI-powered responses
- 🎨 Clean and user-friendly interface
- 📋 Copy generated code with one click
- 🔄 Generate new code instantly
- 📱 Responsive design

## 📖 How It Works

1. Enter a coding prompt.
2. Click Generate Code.
3. The AI processes your request.
4. Generated code is displayed instantly.
5. Copy and use the generated code.
